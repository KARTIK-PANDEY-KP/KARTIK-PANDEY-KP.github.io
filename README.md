# kartik-pandey-kp.github.io

Source for Kartik Pandey's portfolio at <https://kartik-pandey-kp.github.io/>.

Plain static HTML and CSS with one small optional script. No build step, no
dependencies, no web fonts (system font stacks only), no tracking.

- `index.html` – the page
- `assets/styles.css`, `assets/main.js` – styling and scroll-reveal enhancement
- `assets/hero-art.svg` – original artwork, generated by `tools/build_art.py`
- `assets/og.png` – social preview image (original artwork)
- `robots.txt`, `sitemap.xml`, `404.html`, `.nojekyll`

Preview locally with `python3 -m http.server` from this directory.
